# NightInDvoika — Ночь в Двойке

Двухпользовательская многопользовательская игра на Java с JavaFX, вдохновлённая механиками "Five Nights at Freddy's". Один игрок защищает офис, другой управляет атакующими существами.

---

## Технологии

- **Java 21**, **JavaFX 23.0.1** (FXML)
- **Apache Maven** — сборка, многомодульный проект
- **Java Sockets** — клиент-серверное взаимодействие по TCP
- **Lombok**, **JUnit 5**

---

## Геймплей

Игровая сессия длится **6 игровых часов** (≈9 минут реального времени).

- **Атакующий побеждает**, если все 4 существа доберутся до офиса
- **Защитник побеждает**, если переживёт ночь

---

## Роли

### Защитник (Охранник)

Наблюдает за офисом через камеры и следит за перемещением существ.

| Способность | Перезарядка | Длительность | Описание |
|---|---|---|---|
| Радар | 300 с | 10 с | Показывает позиции всех существ |
| Электрошок | 350 с | 30 с | Парализует всех уязвимых существ |
| Маска | — | Переключатель | Защищает от существ, боящихся маски |

### Атакующий

Управляет 4 существами, продвигающимися к офису по заданным маршрутам.

| Способность | Перезарядка | Длительность | Описание |
|---|---|---|---|
| Глушение звука | 240 с | 30 с | Отключает звук на всех камерах |
| Отключение камер | 180 с | 30 с | Затемняет все камеры |
| Паралич защитника | 400 с | 15 с | Блокирует действия защитника |

---

## Существа

| Существо | Маршрут | Перезарядка хода | Реакция на звук | Уязвимо к маске | Видно на радаре | Уязвимо к шоку |
|---|---|---|---|---|---|---|
| **Zombie** | 1→5→6→12→11→14→15 | 20 с | Идёт к звуку | Нет | Да | Да |
| **Skeleton** | 1→5→7→14→13→15 | 10–30 с (случайно) | Избегает звук | Да | Да | Да |
| **Creeper** | 2→4→3→11→14→15 | 25 с | Идёт к звуку | Нет | Нет | Нет |
| **WitherSkeleton** | 2→4→7→... (2 варианта) | 15 с | Избегает звук | Да | Да | Да |

---

## Сетевая архитектура

- Протокол: **TCP сокеты**, сериализация Java объектов
- Порт: **443** (localhost)
- Сервер ожидает подключения двух клиентов, затем синхронно запускает игру для обоих
- Все игровые действия (ходы существ, способности) передаются через сервер

---

## Сборка и запуск

**Требования:** JDK 21, Maven 3

```bash
# Сборка
mvn clean package

# Запуск сервера
java -cp game/target/classes ru.itis.server.Server

# Запуск клиента (JavaFX UI)
mvn -f game/pom.xml javafx:run
```

Оба игрока запускают клиент и подключаются к одному серверу. Первый подключившийся становится атакующим, второй — защитником (или наоборот, в зависимости от выбора в главном меню).

    └── static/                         # Изображения и звуки
